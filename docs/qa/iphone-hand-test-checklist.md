# Pokefish iPhone 手持验收清单

用途：这份清单只覆盖自动 QA 无法替你判断的真实手感和视觉观感。自动侧已由 `godot/scripts/qa/run_all_qa.sh` 覆盖。

## 准备

1. 确认 iPhone 上已启动 `Pokefish`。
2. 点击顶部菜单按钮打开 QA 面板。
3. 保持竖屏，按正常单手握持方式操作。

## 必测项

- 点鱼：点击水域里的鱼，QA 面板的 Event/命中信息应增加，空白水域不应误判为点鱼成功。
- 底部 Dock：打开投喂、伙伴、进化弹层后，底部主动作和模式 Dock 不应被遮挡或吃掉触摸。
- 内容拖拽：在弹层或孵化、图鉴、远行、目标面板的内容区域中间上下滑动，不应只能拖最右侧滚动条。
- 返回水域：从所有二级模块返回水域后，鱼、伙伴浮标、主动作和模式 Dock 都应继续可点。
- Home Indicator：底部按钮不应贴住或压住 iPhone Home Indicator 区域。
- 字体观感：正文和小字应清楚、柔和、贴合游戏风格；如果仍显得系统工具感太重，下一步换更合适的 OFL 字体。
- 图标识别：底部三个主动作和四个模式入口应不依赖长文字也能理解大意。
- 视觉密度：首页应像手机游戏主界面，不应像网页表单或后台面板。
- 水域主角感：首页第一眼应先看到鱼、水面、泡泡和环境层次，而不是先看到 HUD 或底部工具栏。
- 模块场景感：孵化应像孵化设施，图鉴应像收集册，远行应像海域地图，目标应像任务板和宝箱。
- 切换动效：打开模块、展开模块菜单、返回水域时应有轻量动效，不应生硬闪现或拖慢操作。
- 触摸反馈：主动作、模块入口、返回、领取、孵化/购买按钮按下时应有一致反馈，滚动时不应误触或卡住。
- 长时间手感：连续投喂、收取、切模块、滚动 3-5 分钟后，不应出现明显疲劳、误触、卡顿或别扭感。

## QA 面板判读

- `图标看`：主动作和模式入口的图标含义需要肉眼确认。
- `游戏看`：首页视觉密度、层次和趣味性需要肉眼确认。
- `字体看`：正文/小字是否贴合风格需要肉眼确认。
- `单手看`：单手握持时主流程是否自然需要肉眼确认。
- `长时间手感`：连续操作后的误触、疲劳和节奏感需要肉眼确认。

## 通过标准

- 没有明显遮挡、误触高发区、滚动死角或文字溢出。
- 单手主要操作能自然完成。
- 字体和 UI 风格主观上可以接受；若不满意，记录具体位置和原因后继续调。
